# Unicode grapheme data provenance

`src/rope/unicode_grapheme_data.zig` and `tests/grapheme_conformance_data.zig`
are generated by `tests/generate_grapheme_data.py` from the published
`unicode-segmentation` crate version 1.13.3.

That crate identifies its generated tables and grapheme test data as Unicode
17.0.0 data. Its `src/tables.rs` supplies the complete grapheme property table,
including `Extended_Pictographic` and `InCB=Consonant`. Its
`tests/testdata/mod.rs` embeds the official Unicode 17
`GraphemeBreakTest.txt` vectors, split into extended/legacy-common and
extended/legacy-different arrays. The generated Zig test artifact contains all
766 translated official rows plus the crate's two extended-grapheme regression
vectors, for 768 embedded vectors total.

Regenerate from a local Cargo cache with:

```sh
python3 tests/generate_grapheme_data.py \
  --crate /path/to/unicode-segmentation-1.13.3 \
  --rope .
```
