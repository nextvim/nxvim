# Pinned Vim runtime fixtures

`colors/desert.vim` is an unmodified copy of [`runtime/colors/desert.vim`](https://github.com/vim/vim/blob/v8.2.0000/runtime/colors/desert.vim) from the upstream Vim `v8.2.0000` tag.

It is pinned so tests do not depend on the host machine's Vim installation or on changes to newer generated colorscheme files.
